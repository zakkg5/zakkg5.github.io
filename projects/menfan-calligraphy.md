## 二、已完成:Illustrator 向量化

### 來源檔問題

原始素材是「拍攝螢幕」的照片,非掃描檔,解析度受限。
**若能取得原稿重新掃描(建議 600dpi 以上),品質會明顯提升。**

### 影像描圖最終參數

| 項目 | 設定值 | 備註 |
|---|---|---|
| 模式 | 黑白 | |
| 臨界值 | 115 | 太低筆畫變瘦、飛白斷裂;太高會把九宮格線一起描進來 |
| 路徑 | 85% | 曾誤設 50%,導致轉折被磨圓,已修正 |
| 轉角 | 70% | 書法轉折多,不宜過低 |
| 雜訊 | 20 px | 過高會吃掉飛白與細筆鋒 |
| 建立 | 僅填色 | 不勾筆畫 |
| 將曲線靠齊至線段 | 不勾 | 書法無直線 |
| 忽略白色 | ✅ 勾選 | 關鍵,避免描出白底方塊(顏色數由 2 降為 1) |

### 後續處理流程

1. 面板右下「描圖」套用
2. 上方控制列或 `物件 > 影像描圖 > 展開`(**不是** `物件 > 展開` 的通用對話框)
3. `Ctrl+Shift+G` 解散群組
4. 刪除九宮格線(展開後為獨立細長路徑)
5. `物件 > 路徑 > 簡化` 減少錨點

### 無 Photoshop 時的清圖替代方案

- 方法一:描圖後直接刪格線路徑(**已採用**)
- 方法二:`效果 > 影像效果 > 曝光度` 或 `高斯模糊 0.5–1px` → `物件 > 點陣化` → 再描圖
- 方法三:降低臨界值讓格線先消失(代價是筆畫變瘦)
- 免費工具:Photopea(瀏覽器版,介面近似 PS)、GIMP

## 三、目前進度:SketchUp 建模

### 已知狀況

- DWG 匯入 SketchUp 只有線、沒有面,無法推拉
- 四個字為散落幾何體(loose geometry),互相沾黏,選取時會連帶選到隔壁

### 成面方法

1. 用直線工具沿封閉輪廓重描一條邊 → 自動補面
2. 若失敗,多半是**尺寸太小**(SketchUp 忽略 <1mm 的線)→ 放大 100 倍成面後再縮回
3. 檢查線是否共面(Z 軸偏差)、輪廓是否有缺口
4. 建議外掛:**Make Faces**(TIG)、**CleanUp³**

### 分組方法

- 切上視圖 → 由左往右框選(藍色實線框,只選完整包住的)→ 右鍵製作群組
- 四字各自成組,之後調字距／改材質／單獨刪除都不受影響
- 記得刪除多餘的面:九宮格外框、字內鏤空區(「每」的圈、「飯」的口)

### SketchUp 推論點注意事項

- 端點／中點／交點**永遠開啟**,無法關閉
- 抓不到點最常見原因:`視窗 > 模型資訊 > 單位` 的「**啟用長度鎖點**」沒關掉
- `Shift` 鎖定推論、方向鍵鎖軸(↑ 藍軸 ← 綠軸 → 紅軸)

## 四、設計方向(已確認)

### 採用方案:立體切字 + 單一投射燈造影

黑色立體字離牆架高,側上方單一投射燈打光,在牆面投出偏移的灰階影子。
一實一虛,靠光影而非材質堆疊產生層次。

### 規格建議

| 項目 | 建議值 | 說明 |
|---|---|---|
| 材質 | 消光黑鐵件 3–5mm | 不反光才能維持剪影感;古銅色可呼應 80 年代黃銅語彙 |
| 出挑距離 | 10–20mm | 距離越遠影子偏移越大;書法筆畫細,過遠顯單薄 |
| 單字尺寸 | 12–18cm(先試 15cm) | 以門高 210cm 推算 |
| 整體寬度 | 門框寬度的 65–75% | 目前模型中幾乎與門同寬,偏大 |
| 加工方式 | 雷射切割或水刀 | 直接提供 AI 向量檔給廠商 |
| 固定 | 背面焊短柱 | |

### 照明規格

- 位置:字的正上方偏前,距牆 15–25cm
- 光束角:24–36 度(窄角較有戲劇性)
- 色溫:2700–3000K
- **必須單一光源**,多光源會產生重疊影子,效果全毀
- 需確認周圍嵌燈不會打到這面牆

### 排版待調整

1. **垂直位置**:目前重心偏上。建議字到門框上緣 ≈ 1 字高,字到天花 ≈ 1.5–2 字高(上鬆下緊)
2. **水平對齊**:以門框中心線對齊,非牆面中心(牆右側有轉角)
3. **視覺重心**:「每」長橫往左伸、「忘」捺往右收,純數學置中會顯偏左
4. **字距**:「不—忘」之間目前偏寬,需靠眼睛調到視覺一致
5. Illustrator 分佈間距:`Shift+F7` → 面板選單勾「顯示選項」→ 先點關鍵物件 →
   用「分佈間距」(**非**「分佈物件」)

### 風險提醒

參考案例用的是「山田」這種直線筆畫的字,影子錯開後仍清晰。
行書筆畫有粗細變化與連筆,影子疊上去可能糊成一團。
**建模後務必先在 Enscape 試打燈確認可讀性。**
若太亂,可縮小出挑距離(影子貼近本體,接近浮雕效果),或改為直排／減少字數。

## 五、備選方案(已評估未採用)

| 方案 | 說明 | 不採用原因 |
|---|---|---|
| 行燈式燈箱 | 木框 + 和紙面板,內部打光 | 店舖感過重,與住宅調性不符 |
| 木雕匾額 + 洗牆燈 | 實木陰刻／陽刻 + 細長投射燈 | 質感沉穩但偏傳統,當代感不足 |
| 背光切字 | 立體字背後藏 LED 打牆 | 與空間調性最搭,但 80 年代感弱 |
| 壓克力導光板 | 側邊導光,字會發亮 | 商業感重,住宅不適合 |
| 貼在門楣木料上 | 直接貼門框上冒頭 | 省工省錢的備案,但無影子效果 |
