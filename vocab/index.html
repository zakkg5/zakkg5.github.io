單字只存在這台裝置的瀏覽器裡。換手機、清瀏覽資料之前，先匯出一份 JSON 收好。

要一次加很多字：按「複製格式說明」，貼進 Claude 對話請它產生 JSON，然後把整段 JSON 貼到下面的「一次貼多筆」就好——不必存檔。已經存成檔案的話用「匯入 JSON」。兩種都是合併，不會蓋掉現有的單字；同一個字會更新內容，熟悉度取兩邊比較高的。
